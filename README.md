# ادرس معي - Study With Me

منصة Static لطلاب التوجيهي في غزة وفلسطين، مبنية فقط بـ HTML5 وCSS3 وVanilla JavaScript وJSON وlocalStorage.

## التشغيل

### GitHub Pages
1. ارفع المجلد كما هو إلى مستودع GitHub.
2. من Settings → Pages اختر النشر من الفرع الرئيسي ومن مجلد الجذر.
3. افتح رابط GitHub Pages بعد اكتمال النشر.

### محلياً
لأن المتصفحات تمنع `fetch()` لملفات JSON عند استخدام `file://` في حالات كثيرة، شغّل Local Server. مثال باستخدام Python:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000/`.

## البنية

- `data/content.json`: كل المصادر والبيانات القابلة للتعديل.
- `js/data.js`: تحميل JSON والتعامل مع فشل التحميل.
- `js/library.js`: المكتبة والمواد والفروع.
- `js/exams.js`: صفحة الاختبارات والفلاتر.
- `js/search.js`: البحث الشامل.
- `js/calculator.js`: حاسبة المعدل التقديرية.
- `js/physics-laws.js`: قوانين الفيزياء المنظمة والمؤكدة الموجودة في JSON.
- `js/pomodoro.js`: Pomodoro.
- `js/tasks.js`: المهام.
- `js/dashboard.js`: لوحة الطالب.

## الخصوصية

لا يوجد Backend ولا Database ولا تسجيل دخول. بيانات الطالب التي تنشئها الأدوات مثل المهام والملاحظات والمعدل تحفظ محلياً في `localStorage`.

## ملاحظة عن الحاسبة

قواعد احتساب المعدل الرسمي قابلة للتحديث من `content.json`. في النسخة الحالية لم يتم تثبيت قواعد رسمية غير مؤكدة، لذلك الناتج تقديري وليس نتيجة رسمية.

## الروابط الخارجية

الموقع يفهرس روابط خارجية ولا يستضيف الملفات. الروابط قد تتغير أو يتغير محتواها من أصحابها.
